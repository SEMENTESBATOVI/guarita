# Guarita Batovi

Controle de entrada e saída de veículos da portaria da Fazenda Batovi (Sementes Batovi).

- Site: https://sementesbatovi.github.io/guarita/
- Os registros ficam na Planilha Google "GUARITA BATOVI — Controle de Entrada e Saída" (conta conferencia.batovi@gmail.com).
- O site só abre com o código de acesso definido na aba CONFIG da planilha.
- Se o App da Web for reimplantado com link novo, troque `window.GUARITA_API` no topo do `index.html`.
